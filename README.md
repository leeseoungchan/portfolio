# dltjdcks 소개 페이지

React와 Vite로 만든 한국어 자기소개 웹사이트입니다. 별명, 관심사, 잘하는 것과 배우고 싶은 것, 활동·작품, 앞으로의 목표를 한 페이지에서 소개합니다. 상단 메뉴를 누르면 각 섹션으로 이동합니다.

작품은 아직 등록되어 있지 않으며, 준비되면 `src/App.jsx`의 작품 영역에 추가할 수 있습니다. 페이지에는 전화번호·주소·생년월일 등 개인 연락처 정보를 넣지 않습니다.

## 실행하기

Node.js 24 LTS를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 주요 파일

- `src/App.jsx`: 자기소개 내용과 페이지 섹션
- `src/App.css`: 섹션 레이아웃과 반응형 스타일
- `src/index.css`: 전역 글꼴, 색상, 포커스 및 모션 설정
- `public/`: 정적 파일을 둘 수 있는 폴더

## 확인 명령

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist/` 폴더에 만듭니다.
